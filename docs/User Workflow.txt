LGO User Workflow
=================

How to go from in-game export to optimization report.

Assumes the in-game plugin, the bookmarklet, and the lgo binary are
already installed. (Installation instructions: TBD, separate document.)

Summary brief here, detailed instructions below:
-----------------------------------------------
1. Put candidate gear in the in-game Shared Storage chest named `lgo`.
2. Run `/lgo export` in-game → one `lgo_gearlist_*.plugindata` file is written.
3. Open https://lotro-wiki.com in a browser.
4. Click the **LGO Stats** bookmarklet.
5. Paste the contents of `lgo_gearlist_*.plugindata` when prompted.
6. The bookmarklet builds a `.toml`. The summary panel categorises items into three groups: directly resolved, auto-picked from disambiguation variants (informational — the chosen wiki page is listed for audit), and needs-hand-edit. Items in the last group are written with all stats `= 0` and a typed `# UNRESOLVED: ...` comment explaining why; the user fills these in by inspecting their gear in-game.
7. Save the `.toml` to the `AllServers` directory as `lgo_<character>_stats.toml` (the bookmarklet's transient output; overwritten on each re-export).
8. Run `lgo resolve-slots` — reads `lgo_<character>_stats.toml`, looks each item up in `data/lgo_items.json`, merges into the canonical `lgo_<character>_gear.toml` (the sole input the optimizer reads). On every iteration items already present in the canonical file are **preserved verbatim** (so hand-edits to legendary stats, essence sums, etc. survive); items absent from the new export are removed. Pass `--force` (alias `-f`) to opt into per-item prompts before overwriting or removing entries; identical-data items remain a no-op even under `--force`.
9. Run `lgo optimize tm:<number> cr:<number> fn:<number>` (etc.) — The Optimizer prefers `lgo_<character>_gear.toml`, falling back to legacy `lgo_stats_*.toml` only if the canonical file does not yet exist.

=================
Full Instructions
-----------------

1. In LotRO, place the gear items you want considered into the Shared
   Storage chest you have renamed 'lgo' (or 'LGO'). Items already
   equipped on the character are picked up automatically and do not
   need to go in the chest.

2. In the LotRO chat window, type:

       /lgo export

   The plugin writes one file into your character's plugin-data
   directory:

       lgo_gearlist_<character>_<timestamp>.plugindata

3. Open https://lotro-wiki.com in your web browser. You must be on
   lotro-wiki.com before clicking the bookmarklet; it will refuse to
   run on any other site.

4. Click the 'LGO Stats' bookmarklet/link/button in your bookmarks bar.

5. When prompted, paste the entire contents of the
   lgo_gearlist_<character>_<timestamp>.plugindata file you just generated.

6. Wait while the bookmarklet looks each item up on the wiki. It should only take 5-10 seconds.
   (Depending on your Internet connection) The bookmarklet builds a `.toml` file. The summary panel categorises items into three groups: directly resolved, auto-picked from disambiguation variants (informational — the chosen wiki page is listed for audit), and needs-hand-edit. Items in the last group are written with all stats `= 0` and a typed `# UNRESOLVED: ...` comment explaining why; the user fills these in by inspecting their gear in-game.
   Progress is shown on the page. When it finishes, it  displays a 'Resolved / Unresolved' summary and a text area containing the generated TOML.

7. Click 'Select All', copy the text, and save it into your character's
   AllServers directory as:

       lgo_<character>_stats.toml

   This is the bookmarklet's transient output. The next step (8) reads
   it, merges it with the canonical gear file, and is what writes the
   file the optimizer actually uses.

8. From a command prompt, run:

       lgo resolve-slots

   This reads the .toml you just saved, looks each item's slot up in
   the local item database, and adds the slot names to those items.
   
   Items not in the database keep their original slot value (usually
   'Unknown'). Their names are printed to the terminal so you know
   which entries in the 'lgo_<character-name>_gear.toml' file may need hand-editing.
   
   If there is a pre-existing .toml file, it will not overwrite any items already present. (Thereby preserving any hand-edits you make) However, you may force the program to overwrite any edits you may have made previously by using the --force switch, as follows:
   
    lgo resolve-slots --force
  or just
    lgo resolve-slots -f
   
   8a. This database may in the future need to be updated as content 
   is added to LotRO. The way to do this is:
    1. Download a new copy of items.xml from this URL:
       https://github.com/LotroCompanion/lotro-items-db/blob/master/items.xml
    2. Save it inside the 'lgo/data' folder. (Overwrite the existing one) 
    3. Run this command:  lgo build-db

9. You will probably (optional) need to open the final .toml file in 
   a text editor and review it. You may need to hand-edit some kinds of 
   data:
       - Legendary Items
       - Essence stats: add (sum) them into the item stats
       - Items flagged with '# WARNING: all stats unknown' (the
         bookmarklet could not find them on the wiki). Fill in the
         stat values by hand.
       - Items left with slot = "Unknown" by step 8. Fill in the
         correct slot by hand.

   In practice, hand-editing is most often needed for legendary
   items, recently renamed items, and very new items.


10. From the command prompt, run the optimizer with your stat goals,
    in priority order:

        lgo optimize tm:450000 cr:350000 fn:0

    The first stat is maximised first; later stats are used only as
    tiebreakers. A minimum of 0 means 'maximise but no floor required'.
    Two-letter abbreviations and full stat names are both accepted;
    see the Command Line Reference for the full list.

11. Read the report printed to the terminal. It lists the chosen item
    for each gear slot and the resulting total for each tracked stat.


Iteration
---------

- To change the set of items being considered: rearrange gear in
  LotRO, then repeat from step 1.

- To re-run with different stat goals on the same gear: just repeat
  step 10 with new goals. Steps 1-9 do not need to be redone.

- To hand-correct stats or slots: edit the 'lgo_<character-name>_gear.toml' file, then
  re-run step 10.
