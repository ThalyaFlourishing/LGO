LGO User Workflow
=================

How to go from in-game export to optimization report.

Assumes the in-game plugin, the bookmarklet, and the lgo binary are
already installed. (Installation instructions: TBD, separate document.)

===============================================
Short User Instructions (detailed instructions below)
-----------------------------------------------
1. Put candidate gear in the in-game Shared Storage chest named `lgo`.
2. Run `/lgo export` in-game. Equipped items are exported automatically; equipped craft tools and bridles are excluded (no need to unequip them). A `lgo_gearNames_*.plugindata` file will be saved in your plugindata folder.
3. Open https://lotro-wiki.com in a browser. The bookmarklet will not work on any other site.
4. Click the **LGO Stats** bookmarklet. A small pop-up will appear.
5. Copy and paste in the contents of `lgo_gearNames_*.plugindata` , then hit 'OK'.
6. The bookmarklet builds a `.toml` file. (Scroll down)
7. Save the `.toml` to the `AllServers` directory as `lgo_<character-name>_gearStats.toml`.
8. Open a a command-line window on your computer and run `lgo resolve-slots`.
9. Run `lgo optimize tm:450000 cr:350000 fn:0`, replacing those values with your actual stat goals. The Optimizer will then try every combination of gear to see if it is possible to reach those values. If it finds some, it picks the best one and shows you in the terminal window, and writes and HTML file which you can bookmark in your browser for easy viewing.


======================
Detailed User Instructions
----------------------

1. In LotRO, rename a Shared Storage chest 'lgo' (or 'LGO') Place the gear items you want considered into that chest. 
   Items already
   equipped on the character are picked up automatically and do not
   need to go in the chest. Your equipped craft tool and bridle are
   automatically skipped — you do not need to unequip them. Do not
   place craft tools or bridles in the `lgo` chest; they are not
   optimizer candidates.

2. In the LotRO chat window, type:

       /lgo export

   The plugin writes one file into your character's plugin-data
   directory:

       lgo_gearNames_<character-name>_<timestamp>.plugindata
       
   This file is a list of all the items you currently have equipped, plus all the ones you put in the 'lgo' shared-storage chest, plus your character's name and base stats. Unfortunately getting item stats from LotRO is *extremely* difficult, so this file is not the last one you have to make, sorry. :(

3. Open https://lotro-wiki.com in your web browser. You must be on
   lotro-wiki.com before clicking the bookmarklet; it will refuse to
   run on any other site.

4. Click the 'LGO Stats' bookmarklet/link/button in your bookmarks bar.

5. When prompted, paste the entire contents of the
   lgo_gearNames_<character-name>_<timestamp>.plugindata file you just generated.

6. Wait while the bookmarklet looks each item up on the wiki. It usually takes 5–10 seconds, depending on your internet connection. Progress is shown on the page. When it finishes, it shows a summary of how many items were found cleanly, how many had to be picked from a list of variants automatically, and how many it could not find at all. The unfound items appear in the output with all stats set to 0 and a comment line beginning # UNRESOLVED: explaining why. You will need to fill those stats in by hand later (step 9). The bookmarklet then displays a text area containing the generated file.

7. Hit the 'Save TOML' button and save the file in this folder:

C:\Users\ <YOUR USER NAME> \Documents\The Lord of the Rings Online\PluginData\<YOUR CHARACTER NAME>\AllServers

 and name the file:

lgo_<character-name>_gearStats.toml

If that doesn't work, click 'Select All', copy the text, paste it into a new file and *then* save it.

(Replace <character-name> with your character's name, exactly as LotRO spells it. The next step reads this file and combines it with your saved gear file; you will not need to look at this file directly.)

8. From a command prompt, run:

       lgo resolve-slots

   This reads the stats .toml file you just saved, looks each item's slot up in
   the local item database, and adds the slot names to those items.
   
   There may be items not found in the database. They will keep their original slot value (usually 'Unknown'). Their names are printed to the terminal window so you know which entries in the 'lgo_<character-name>_gearReady.toml' file are likely to need hand-editing.
   
   The first time you run this command, it creates a file called lgo_<character-name>_gearReady.toml. On subsequent runs, it reads that file and adds any new items to it. Items already in the file are kept exactly as they were — so any stats you have hand-edited (for legendary items, essences, etc.) are safe, even if the latest bookmarklet output disagrees with them. If an item is no longer in your gear export (you moved it, sold it, decon'd it, etc.), it is removed from the file.
   
   To force the new bookmarklet output to overwrite your existing file, add --force (or its short form -f):

      lgo resolve-slots --force

   In --force mode, the program will ask you, item by item, before changing or removing anything. Each prompt looks like:

      Overwrite stats for "Test Helm"? (y/n/a)

   or:

      Remove "Old Sword" (no longer in export)? (y/n/a)

   Type y to allow the change, n to keep your existing data, or a to allow that kind of change for all remaining items without further prompting (overwrites and removals are tracked separately, so an a to one kind does not automatically apply to the other).
   
   NOTE:. That local item database may in the future need to be updated as content is added to LotRO. The way to do this is:
    1. Download a new copy of items.xml from this URL:
       https://github.com/LotroCompanion/lotro-items-db/blob/master/items.xml
       If that link no longer works, tell Thalya via in-game mail in LotRO.
    2. Save it as 'items.xml' inside the 'data' folder. (Overwrite the existing one) 
    3. Run this command:  lgo build-db

9. You will probably (optional) need to open the final .toml file in 
   a text editor and review it. You will need to hand-edit some kinds of 
   data:
       - Legendary Items
       - Essence stats: add (sum) them into the item stats
       - Items flagged with '# UNRESOLVED'.
       - Items left with slot = "Unknown" by step 8.

   In practice, hand-editing is most often needed for legendary
   items, recently renamed items, and very new items.
   
   Open the file with any text editor. (*NOT* a word-processer program like MS Word! Notepad will work, but Notepad++ or VS Code will display it more readably). The file lives in your character's AllServers directory, the same place you saved the file in step 7. The filename is lgo_<character>_gearReady.toml.


10. From the command prompt, run the optimizer with your stat goals,
    in priority order:

        lgo optimize tm:450000 cr:350000 fn:0

    The first stat is maximised first; later stats are used only as
    tiebreakers. A minimum of 0 means 'maximise but no floor required'.
    Two-letter abbreviations and full stat names are both accepted;
    see the Command Line Reference for the full list.

11. Read the report printed to the terminal. It lists the chosen item
    for each gear slot and the resulting total for each tracked stat.


Iteration
---------

- To change the set of items being considered: rearrange gear in
  LotRO, then repeat from step 1.

- To re-run with different stat goals on the same gear: just repeat
  step 10 with new goals. Steps 1-9 do not need to be redone.

- To hand-correct stats or slots: edit the 'lgo_<character-name>_gearReady.toml' file, then
  re-run step 10.
